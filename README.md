# Online Tuition & Tutor Booking System

## 📌Project Overview

The Online Tuition & Tutor Booking System is a web-based platform designed to connect students with tutors and simplify the process of finding tutors, booking tuition sessions, managing assignments, homework, marks, payments and feedback.

## 🎯Objectives

- Help students find suitable tutors
- Provide an easy tutor booking system
- Allow tutors to manage their subjects and availability
- Manage student and tutor information
- Provide payment and feedback modules
- Provide separate dashboards for Student, Tutor and Admin
